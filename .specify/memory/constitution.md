# Constituição do projeto (Spec-Kit)

Princípios não negociáveis para qualquer funcionalidade gerada por agente neste projeto.

- Determinismo: leitura de dados como texto imutável; nenhuma conversão silenciosa na entrada.
- Testes antes de pronto: toda funcionalidade tem testes derivados dos critérios de aceite.
- Menor privilégio: nenhum código escreve em banco sem passar por revisão humana.
- Idioma: prosa em português, código e identificadores em inglês.
- Sem dependências novas sem justificativa registrada.

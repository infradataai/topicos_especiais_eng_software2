## Engenharia de software e desenvolvimento com IA

| Sigla | Significado |
|---|---|
| SDD | *Spec-Driven Development*, desenvolvimento guiado por especificação |
| EARS | *Easy Approach to Requirements Syntax*, notação de requisitos |
| ADR | *Architecture Decision Record*, registro de decisão arquitetural |
| MADR | *Markdown Architectural Decision Records*, formato de ADR em Markdown |
| MCP | *Model Context Protocol*, protocolo de contexto para agentes |
| C4 | Modelo C4 de diagramas de arquitetura (contexto, contêiner, componente e código) |
| TDD | *Test-Driven Development*, desenvolvimento guiado por testes |
| BDD | *Behavior-Driven Development*, desenvolvimento guiado por comportamento |
| IQR | *Interquartile Range*, amplitude interquartil (detecção de outliers) |
| EDA | *Exploratory Data Analysis*, análise exploratória de dados |
| ORM | *Object-Relational Mapping*, mapeamento objeto-relacional |
| API | *Application Programming Interface*, interface de programação de aplicações |
| STAR | Situação, Tarefa, Ação e Resultado (método de narrativa do post no LinkedIn) |

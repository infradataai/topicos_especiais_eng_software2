# Proposta - Consulta web interativa

## Por que

Os resultados consolidados e os relatorios de qualidade precisam ser consultados diretamente por usuarios sem acesso manual ao SQLite.

## O que muda

Adiciona uma interface web de consulta somente leitura para filtrar fontes, lotes e registros consolidados e visualizar resultados paginados.

## Fora de escopo

A interface nao permite editar dados, executar SQL arbitrario, ingerir arquivos ou substituir a autenticacao e autorizacao corporativas.
